# Sprint 4 — Análise Estatística de Dados

Projeto desenvolvido durante o bootcamp de Data Analytics da TripleTen.

## Objetivo

Analisar o comportamento de clientes da empresa de telecomunicações Megaline para identificar qual dos planos pré-pagos gera maior receita.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## O que foi realizado

- Limpeza e preparação dos dados
- Análise exploratória de dados
- Análise estatística de utilização dos planos
- Cálculo de médias, variância e desvio padrão
- Testes de hipóteses
- Criação de gráficos para visualização de padrões e tendências

## Conclusão

O projeto permitiu aplicar conceitos de estatística e análise de dados para apoiar decisões de negócio baseadas em dados reais.
